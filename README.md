# PT Link

หน้าเว็บสำหรับหุ่น PT ROBOTICS: ดูสถานะ เซนเซอร์ คาลิเบรต กราฟการวิ่ง และอัปเดตเฟิร์มแวร์

ใช้ Chrome หรือ Edge บนคอม เสียบสาย USB เข้าหุ่น แล้วกด "เชื่อมต่อผ่าน USB"
เปิดครั้งแรกตอนมีเน็ต หลังจากนั้นใช้ออฟไลน์ได้

ไฟล์ใน repo นี้สร้างอัตโนมัติจาก repo หลัก — อย่าแก้ที่นี่
